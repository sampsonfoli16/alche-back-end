# Web Infrastructure - API

This project uses the JSONPlaceholder REST API to gather employee TODO
list data and export it in different formats.

## Files

- 0-gather_data_from_an_API.py: prints an employee's TODO list progress.
- 1-export_to_CSV.py: exports one employee's TODO data to USER_ID.csv.
- 2-export_to_JSON.py: exports one employee's TODO data to USER_ID.json.
- 3-dictionary_of_list_of_dictionaries.py: exports all employees' TODO
  data to todo_all_employees.json.

## Usage

python 0-gather_data_from_an_API.py <employee_id>
python 1-export_to_CSV.py <employee_id>
python 2-export_to_JSON.py <employee_id>
python 3-dictionary_of_list_of_dictionaries.py
